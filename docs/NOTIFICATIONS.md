# 📬 Настройка уведомлений в Telegram и ВКонтакте (`v3.2.29`)

Руководство для актуальной редакции **[Avito Parser Community Edition](https://github.com/eminsk/parser_avito)** (поддержка отдельных прокси для Telegram, отслеживание падения цен в SQLite и отправка карточек в группы/каналы).

---

## 1. Уведомления в Telegram-бота, группу или канал

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и создайте нового бота командой `/newbot` — сохраните выданный **Bot Token**.
2. Определите `chat_id` получателя:
   - **Личный чат:** отправьте боту `/start` и узнайте свой числовой ID через [@userinfobot](https://t.me/userinfobot).
   - **Канал или группа:** добавьте бота администратором в канал/группу и укажите публичный `@username` канала или числовой ID формата `-100xxxxxxxxxx`.
   - Можно указать **несколько получателей** построчно в поле `Chat id telegram` (или через список в `config.toml`).
3. **Если Telegram недоступен в вашей сети (`api.telegram.org` не отвечает):**
   - Укажите отдельный прокси в поле **`Прокси для tg`** (`user:pass@ip:port` или `socks5://...`). Он используется **только** для доставки уведомлений и не влияет на прокси парсинга Авито.
4. Нажмите кнопку **«Проверить tg»** — если токен и `chat_id` указаны верно, бот мгновенно доставит тестовое сообщение с ценой.
5. **Отслеживание снижения цен (`SQLite`):** при повторном обнаружении уже виденного объявления с изменившейся ценой уведомление автоматически покажет старую и новую цену.

> 💡 **Нужны готовые конфиги, помощь с прокси или обновления парсера?** Подписывайтесь на **[@avito_sdk_pro](https://t.me/avito_sdk_pro)** (есть живой чат в комментариях).  
> Если нужна сверхлёгкая версия **без Playwright** (`~28 МБ .exe`), интерактивный Telegram-контроллер (`/search`, `/proxy`, `/workers`) и выгрузка `.xlsx` прямо в чат — попробуйте **[Avito SDK Pro](https://github.com/eminsk/avito-sdk)**.

## 2. Настройка уведомлений ВКонтакте (VK API)

1. Создайте новое сообщество (или используйте существующее): [vk.com/groups](https://vk.com/groups?w=groups_create_new).
2. Откройте **Управление сообществом → Дополнительно → Работа с API → Ключи доступа**.
3. Создайте ключ сообщества с правами на **отправку сообщений** и **доступ к фотографиям**.
4. Вставьте токен в поле `Token VK` и укажите числовой **User ID** получателя (только цифры из `https://id.vk.com/account/#/personal`, например `1234567`, без буквенного псевдонима).
5. Откройте диалог со своим сообществом в ЛС, отправьте любое приветственное сообщение и разрешите приём сообщений от группы.
6. Проверьте доставку кнопкой **«Проверить VK»**.

> **Порядок доставки:** при одновременном включении Telegram и ВКонтакте сначала отправляются сообщения в Telegram (быстрее и с поддержкой Markdown/превью), затем в VK.
